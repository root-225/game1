# Dépôt des assets à intégrer

Mets ici les packs téléchargés (zip ou dossiers décompressés), puis commit + push
sur la branche `claude/eloquent-ramanujan-7i3pbf`. Je m'occupe du tri, de l'allègement
et de l'intégration ; ce dossier est exclu des builds.

Packs recommandés (Quaternius, **CC0**, usage commercial OK) :

1. **Ultimate Modular Men Pack** — hommes low-poly réalistes, tenues modernes
2. **Ultimate Modular Women Pack** — femmes, mêmes styles
3. **Universal Animation Library** (optionnel) — course, sprint, roulade, glissade…

Site : https://quaternius.com (menu Packs) ou https://quaternius.itch.io
Prends de préférence le format **glTF / GLB** (sinon FBX, je convertis).

Fichiers > 25 Mo : l'upload web de GitHub les refuse, passe par `git push`.
